# Height4Kid v1.0.2 开发计划

## 概述

本文档详细描述了 Height4Kid 应用 v1.0.2 版本的开发计划，包括优化和修复内容。

***

## 一、优化内容

### 1. 重建国标数据库

**目标**：参照 `儿童生长发育标准数据.md` 的国标数据进行重建，但保留原体重的正常值，体重曲线仅绘制正常值曲线，BMI仅作为评估标准。

**分析**：

- 当前国标数据只包含 1-18 岁的年度数据
- 新国标数据包含从出生到18岁的详细数据（包括月龄）
- 身高标准使用 -2SD, -1SD, 中位数, +1SD, +2SD
- BMI标准使用低体重、正常、超重、肥胖

**实现方案**：

1. 更新 `lib/models/national_standard.dart`：
   - 扩展 `HeightStandard` 类，支持 -2SD, -1SD, 中位数, +1SD, +2SD 五个等级
   - 保留现有的体重标准数据结构（偏瘦/标准/超重/肥胖）
   - 新增 BMI 标准数据结构
   - 更新评估方法，使用新的国标数据
   - 添加BMI评估方法
2. 数据映射：
   - 身高评估标准：
     - 矮小: < -2SD (P3)
     - 偏矮: -2SD \~ -1SD (P3 \~ P15)
     - 正常: -1SD \~ +1SD (P15 \~ P85)
     - 偏高: +1SD \~ +2SD (P85 \~ P97)
     - 超高: ≥ +2SD (P97)
   - BMI评估标准（新增）：
     - 低体重: < 正常下限
     - 正常: 正常范围
     - 超重: 正常上限 \~ 肥胖下限
     - 肥胖: ≥ 肥胖下限
3. 体重曲线绘制：
   - 仅绘制正常值曲线（不绘制BMI曲线）
   - 保留原有的体重曲线，仅供参考，不进行评估，在体重曲线界面，显示BMI和BMI评估结果

### 2. 优化主页下方导航栏UI

**目标**：去掉主页下方的黑条，缩小今日记录与历史记录的字体，把背景框更贴近底部，使它能更好的在手机上显示。

**当前问题**：

- 底部有黑色横条（Home Indicator）
- 字体较大
- 背景框距离底部有间距

**实现方案**：

1. 修改 `lib/main.dart` 中的 `_buildBottomNav` 方法：
   - 移除黑色横条（删除 `Container` 宽度134高度5的黑色条）
   - 缩小字体：从16px缩小到14px
   - 调整内边距：将底部padding从24减小到8或12
   - 调整背景框位置使其更贴近底部

### 3. 实现自动更新功能

**目标**：如果软件能够检查到更新，改为立即更新，直接下载对应地址的.apk文件，并安装。

**当前实现**：

- 仅跳转到GitHub release页面
- 用户需要手动下载安装

**实现方案**：

1. 修改 `lib/utils/update_checker.dart`：
   - 更新版本号为 1.0.2
   - 修改 `UpdateInfo` 类，添加 `apkDownloadUrl` 字段
   - 从GitHub release assets中获取APK下载链接
2. 修改 `lib/main.dart` 中的更新对话框：
   - 移除"跳过此版本"和"稍后提醒"按钮
   - 改为"立即更新"按钮
   - 使用 `dio` 或 `http` 下载APK文件
   - 使用 `open_file` 或 `android_intent_plus` 安装APK
3. 添加依赖：
   - `dio: ^5.0.0` - 用于下载文件
   - `open_file: ^3.3.2` - 用于打开/安装APK
   - `path_provider: ^2.1.5` - 已存在，用于获取下载路径
4. 权限：
   - 需要 `REQUEST_INSTALL_PACKAGES` 权限
   - 需要 `WRITE_EXTERNAL_STORAGE` 权限（Android 10以下）

## 二、修复内容

### 1. 修复国标曲线全屏时历史点切换问题

**问题描述**：安卓端国标曲线全屏时，点击一个历史点查看数据时，不能查看另一个点，需关闭全屏再打开才能重新操作。

**分析**：

- 查看 `growth_chart.dart` 中的 `_FullscreenChartContent` 组件
- 问题可能出在状态管理或点击事件处理

**实现方案**：

1. 检查 `_FullscreenChartContentState` 中的 `_handleFullscreenTap` 方法
2. 确保点击新数据点时能够正确更新 `_selectedRecordIndex`
3. 可能需要添加 `setState` 调用或修复状态更新逻辑
4. 检查是否有点击事件冲突或阻止事件传播的问题

### 2. 修复国标曲线的评估标准与成长状态不一致

**问题描述**：国标曲线的评估标准与原来成长状态的身高体重标识的评估标准不一致，评估标准均参照 `儿童生长发育标准数据.md`。

**分析**：

- 当前 `growth_chart.dart` 中的评估逻辑使用最接近值匹配
- `character_display.dart` 中的评估使用 `StandardData.evaluateHeight/Weight`
- 两者逻辑不一致

**实现方案**：

1. 统一评估逻辑：
   - 修改 `growth_chart.dart` 中的 `_buildRecordInfo` 和 `_buildFullscreenRecordInfo`
   - 使用 `StandardData.evaluateHeight` 和 `StandardData.evaluateWeight` 方法
   - 确保评估标准与 `national_standard.dart` 中定义的一致
2. 更新 `national_standard.dart` 中的评估方法：
   - 确保使用正确的国标数据边界值
   - 身高评估：矮小(<-2SD)、偏矮(-2SD\~-1SD)、正常(-1SD\~+1SD)、偏高(+1SD\~+2SD)、超高(≥+2SD)
   - 体重评估保持原有逻辑

### 3. 在成长状态体重标识下增加BMI标识

**目标**：在体重标识下增加BMI标识，只评估BMI，不评估体重。

**实现方案**：

1. 修改 `lib/widgets/character_display.dart`：
   - 在 `_DataTagWithEval` 组件下方添加BMI显示
   - 计算BMI值：BMI = 体重(kg) / (身高(m))^2
   - 使用BMI标准进行评估
   - 显示格式："BMI: XX.X (评估结果)"
2. 修改数据标签布局：
   - 调整 `_DataTagWithEval` 组件，支持显示BMI信息
   - 或添加新的BMI标签组件

### 4. 确保web端能够正常使用

**目标**：修改与Android端保持一致，修改完内容后，先启动web端测试。

**实现方案**：

1. 检查所有平台特定代码：
   - `dart:io` 的使用（Platform.isAndroid）
   - 文件系统操作
   - 权限请求
2. Web端适配：
   - 自动更新功能在web端应禁用或提供替代方案
   - 文件下载/导出功能使用web兼容的方式
   - 确保所有UI组件在web端正常显示
3. 测试：
   - 运行 `flutter run -d chrome` 启动web端
   - 验证所有功能正常

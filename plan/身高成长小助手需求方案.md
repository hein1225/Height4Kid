## 项目概述与设计理念

### 1.1 项目背景与目标

**产品定位**

身高成长小助手是一款专注于儿童生长发育记录与追踪的安卓应用，旨在帮助家长科学、系统地记录孩子的身高体重变化，并通过可视化曲线和国标对照，让家长直观了解孩子的生长发育状况。产品以"陪伴成长、记录美好"为核心理念，将专业的生长发育知识与温馨可爱的视觉体验相结合，让记录过程充满乐趣而非负担。

**目标用户群体**

本产品主要面向0-18岁儿童的家长，尤其是新手父母和对儿童健康管理有较高需求的家庭。用户通常具有以下特征：关注孩子的健康成长、有记录孩子成长数据的习惯、需要便捷的工具来追踪生长发育趋势、期望获得直观的生长发育评估反馈。

**核心价值主张**

产品解决的核心痛点包括：一是传统记录方式（纸质记录或普通笔记）缺乏可视化对比，难以发现生长异常；二是缺乏科学的评估标准，家长无法判断孩子身高体重是否在正常范围内；三是记录过程繁琐，容易中断，难以坚持。通过本应用，家长可以便捷地记录每次测量数据，自动生成成长曲线，并获得基于国标的生长发育评估，让成长管理变得科学、简单、有趣。

### 1.2 设计理念与风格定位

**整体设计风格**

本应用采用"温暖治愈系"设计风格，以"成长"为核心视觉隐喻，将儿童健康管理的专业性与家庭温馨氛围完美融合。设计风格关键词包括：温暖、可爱、自然、专业、清新。整体视觉语言以圆润的线条、柔和的配色、卡通化的角色形象为主，营造轻松愉悦的使用氛围，同时通过专业的数据可视化传递科学可信的品牌形象。

**视觉差异化**

与市场上常见的儿童健康管理类应用相比，本产品在视觉设计上具有以下差异化特点：首先，采用原创Q版卡通角色作为应用的核心视觉元素，而非简单的图标或照片，增强情感连接；其次，将"成长树"或"小主人公"等成长隐喻融入界面设计，使数据展示更具故事性；最后，通过统一的圆角设计、柔和的阴影效果、精美的装饰元素，打造高品质的视觉体验。

## 软件整体架构

### 2.1 应用结构概览

**核心模块划分**

本应用根据功能职责划分为以下主要模块：

  ------------------------------------------------------------------------------------------
  模块名称             模块职责                                         优先级
  -------------------- ------------------------------------------------ --------------------
  首页模块             展示小孩信息、角色形象、身高体重数据、成长曲线   核心

  成长记录模块         添加今日记录、查看历史记录、管理测量数据         核心

**核心用户流程**

    首次启动 → 新建小孩信息（名称、出生日期、性别、头像）
        ↓
    进入首页 → 查看小孩角色形象 + 身高体重数据
        ↓
    点击记录按钮 → 填写今日身高体重 → 保存记录

    返回首页 → 查看更新后的成长曲线

## Q版角色形象设计规范

### 4.1 角色设计整体风格

**艺术风格定义**

Q版角色采用日式动漫"Q版"（Chibi）风格，特点是头大身小、圆润可爱、五官简化。整体设计遵循以下原则：

- **比例关系**：头部与身体比例约为1:1至1:1.5，突出可爱萌态
- **线条风格**：圆润柔和，无尖锐棱角，边线流畅自然
- **表情设计**：以微笑为主，眼睛大而有神，体现活泼健康的状态
- **色彩搭配**：采用低饱和度的马卡龙色系，温馨柔和
- **动作设计**：静态站立或轻微动态姿势，自然放松

**男女角色差异化设计**

  ------------------------------------------------------------------------------
  差异维度             男童角色                     女童角色
  -------------------- ---------------------------- ----------------------------
  主色调               蓝色系为主（天蓝、海军蓝）   粉色系为主（粉色、珊瑚粉）

  辅色                 黄色、白色                   白色、浅紫色

  发型                 短发，刘海简洁               长发或双马尾，刘海多样

  服装风格             运动休闲、工装               甜美可爱、公主风

  配饰                 运动鞋、双肩包               发饰、蝴蝶结、公主包

### 国标数据使用规则

**评估逻辑**

1.  **身高评估**：
    - 根据小孩性别选择对应数据表
    - 根据小孩年龄（精确到月）查找对应行数据
    - 将当前身高与该年龄段的四个身高标准值比较：
      - 身高 ≤ 身高矮小值 → 评估为"矮小"
      - 身高矮小值 \< 身高 ≤ 身高偏矮值 → 评估为"偏矮"
      - 身高偏矮值 \< 身高 ≤ 身高超高值 → 评估为"标准"
      - 身高 \> 身高超高值 → 评估为"超高"
2.  **体重评估**：
    - 计算BMI = 体重(kg) ÷ 身高(m)²
    - 根据小孩性别和年龄查找对应体重标准
    - 比较当前体重与四个体重标准值：
      - 体重 ≤ 体重偏瘦值 → 评估为"偏瘦"
      - 体重偏瘦值 \< 体重 ≤ 体重超重值 → 评估为"标准"
      - 体重超重值 \< 体重 ≤ 体重肥胖值 → 评估为"超重"
      - 体重 \> 体重肥胖值 → 评估为"肥胖"

**曲线绘制规则**

在成长曲线图表中，国标曲线的绘制方式：

  ----------------------------------------------------------------------
  曲线类型        线条样式        颜色            数据来源
  --------------- --------------- --------------- ----------------------
  身高矮小线      虚线            红色 #FF6B6B    各年龄段"身高矮小"值

  身高标准线      实线            绿色 #4CAF50    各年龄段"身高标准"值

  身高超高线      虚线            紫色 #9C27B0    各年龄段"身高超高"值

  体重标准线      实线            绿色 #4CAF50    各年龄段"体重标准"值
  ----------------------------------------------------------------------

**年龄插值计算**

当小孩年龄不是整数岁时，采用线性插值计算对应标准值：

    插值标准值 = 标准值(年龄下限) + (标准值(年龄上限) - 标准值(年龄下限)) × 月龄/12

例如：5岁6个月的女孩身高标准值 = 身高标准(5岁) + (身高标准(6岁) -
身高标准(5岁)) × 6/12

### 7.1 身高评估标准

  --------------------------------------------------------------------
  评估等级        定义                 颜色标识        显示文字
  --------------- -------------------- --------------- ---------------
  矮小            低于第3百分位数      红色            "矮小"

  偏矮            第3至第25百分位数    橙色            "偏矮"

  标准            第25至第75百分位数   绿色            "标准"

  超高            高于第75百分位数     紫色            "超高"
  --------------------------------------------------------------------

**评估计算逻辑**

    评估结果 = 根据小孩性别 + 年龄（精确到月）+ 当前身高
             → 查找对应百分位数区间
             → 返回评估等级

**评估等级划分**

  -----------------------------------------------------------------------
  评估等级        定义                    颜色标识        显示文字

  标准            BMI第15至第85百分位数   绿色            "标准"

  超重            BMI第85至第95百分位数   金色            "超重"

  肥胖            BMI高于第95百分位数     深橙色          "肥胖"
  -----------------------------------------------------------------------

**BMI计算方式**

    BMI = 体重(kg) ÷ 身高(m)²

所有图片资源均采用PNG格式存放在指定目录，命名规范统一。开发者可通过直接替换对应文件来更新资源，无需修改代码。APK打包时会自动引用drawable目录下的最新资源。

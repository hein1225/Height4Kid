# 儿童生长标准数据

## 评估标准说明

### 身高评估标准（基于百分位）

| 等级 | 百分位范围 | 说明 |
|:----:|:----------:|:-----|
| 矮小 | < P3 (-2SD) | 身高明显低于同龄人，建议就医评估 |
| 偏矮 | P3 ~ P25 | 身高略低于同龄人，建议关注营养 |
| 正常 | P25 ~ P75 | 身高在正常范围内 |
| 偏高 | P75 ~ P97 | 身高略高于同龄人 |
| 超高 | ≥ P97 (+2SD) | 身高明显高于同龄人，建议关注 |

### BMI评估标准（体质指数）

| 分类 | BMI范围 | 说明 |
|:----:|:-------:|:-----|
| 低体重 | < 正常下限 | 体重偏低，需增加营养摄入 |
| 正常 | 正常范围 | 体重在健康范围内 |
| 超重 | 正常上限 ~ 肥胖下限 | 体重偏重，需控制饮食 |
| 肥胖 | ≥ 肥胖下限 | 体重明显超重，建议就医干预 |

> **注**：BMI = 体重(kg) ÷ 身高(m)²

## 数据说明

### SD（标准差）与百分位对应关系

| SD值 | 百分位 | 说明 |
|:----:|:------:|:-----|
| -2SD | P3 | 约3%的儿童低于此值 |
| -1SD | P15 | 约15%的儿童低于此值 |
| 中位数 | P50 | 约50%的儿童低于此值 |
| +1SD | P85 | 约85%的儿童低于此值 |
| +2SD | P97 | 约97%的儿童低于此值 |

### 使用建议

1. **定期测量**：建议每3-6个月测量一次身高体重
2. **绘制生长曲线**：连续测量比单次测量更有意义
3. **关注趋势**：比单次数值更应关注生长速度
4. **综合评估**：结合身高和BMI综合判断儿童生长发育状况
5. **咨询医生**：如有疑虑，请及时就医
